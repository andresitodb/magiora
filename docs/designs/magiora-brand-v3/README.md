# Magiora Brand v3

Canonical direction: approved MA ligature.

## Meaning

The symbol represents union, collaboration, and the transformation of ideas into productions.
It is intentionally industry-neutral so Magiora can serve film, television, theatre, dance,
music, live performance, and other production arts.

## Canonical geometry

- ViewBox: `0 0 85 80`
- Construction: one filled path; no strokes or effects
- Canonical master: `master-symbol.svg`
- Web derivatives: `svg/web/`

## Colors

- Gold: `#DAAF37`
- Soft black: `#0D0D0D`
- Warm beige: `#F5F2EB`
- White: `#FFFFFF`

## Usage

- Use the symbol-only asset for favicon, app icons, avatars, and compact navigation.
- Use horizontal lockups where the full brand name has room to breathe.
- Use `svg/web/magiora-symbol.svg` in inline components so the interface controls the logo color.
- Do not stretch, rotate, add effects, alter the paths, or rearrange the geometry.
- Keep clear space equal to at least one quarter of the symbol width.

## Implementation note

The wordmark lockups use a generic system font stack so they remain portable.
Codex should preserve the symbol geometry exactly, but may replace the text font family
with Magiora's existing production typography.
