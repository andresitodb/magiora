# Magiora Bridge Identity v1.0

## Official mark

The official symbol is a geometric **Bridge M** made from two outer pillars and two diagonal spans meeting at the center.

### Canonical geometry

- `viewBox`: `0 0 64 48`
- Path: `M10 40V8L32 28L54 8V40`
- Stroke width: `5.5`
- Line cap: `square`
- Line join: `miter`
- Fill: `none`

The central point represents the meeting of ideas, talent and production.

## Colors

- Warm neutral: `#F7F6F4`
- White: `#FFFFFF`
- Near-black: `#191715`
- Primary brown: `#6B3F2A`
- Copper accent: `#A86B45`

## Usage

- Navbar: copper mark + existing Magiora serif wordmark.
- Favicon: copper mark on near-black rounded square.
- Light app icon: copper mark on warm neutral.
- Monochrome: near-black or white.
- Minimum recommended size: 20 px. Use the favicon variant below that size.
- Keep clear space around the mark equal to roughly one stroke width.

## Do not

- Add gradients, shadows or 3D effects.
- Round the endpoints.
- stretch or skew the mark.
- place it inside a film frame, camera, play button or clapperboard.
- alter the center point or asymmetrically move either pillar.
- treat the symbol as an envelope, mountain or crown.

## Implementation note

The generic `magiora-bridge-mark.svg` uses `currentColor` and is the preferred source for React components.
